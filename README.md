# Logistikspiel Webprojekt

Dieses Repository enthält das Grundgerüst für ein Webprojekt.

## Struktur

- `index.html` — Startseite des Projekts
- `src/css/style.css` — Basis-Layout und Styles
- `src/js/app.js` — JavaScript-Grundlage

## Starten

Öffne `index.html` direkt im Browser oder benutze einen lokalen Webserver.

## Nächste Schritte

- Füge dein HTML-Layout in `index.html` hinzu
- Erweitere das Styling in `src/css/style.css`
- Implementiere die Projektlogik in `src/js/app.js`
